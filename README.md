# FORGE // UI

An interactive **React + Tailwind CSS v4** component workbench and **AI Prompt Spec generator**. Dial in design tokens, preview components across viewports and themes, and export production-ready JSX or structured AI prompts with one click.

---

## Key Features

- **Live Design Token Controls:** Real-time switching for Accent Palette, Surface Mode (*Solid*, *Glassmorphism*, *Outline*), Border Radius, Padding Scale, and Elevation/Glow.
- **4 Interactive Component Archetypes:** Card, Button, Alert, and Stat Tile with live editable copy.
- **Adaptive IDE Layout:** Pinned live preview with a 3-tab mobile dock (`Tokens` | `Content` | `Code`) on narrow screens; full-viewport split-pane workspace on desktop and ultrawide monitors.
- **Dual Export Engine:** Generates clean, copyable **React + Tailwind JSX** alongside a structured **AI Prompt Spec** for AI-assisted coding workflows.

---
